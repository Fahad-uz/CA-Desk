CA DESK {{VERSION}} - WINDOWS (64-BIT)

1. Extract ALL files from CA-Desk-v{{VERSION}}-win-x64.zip into a folder.
2. Open that folder and double-click CA-Desk.exe.
3. Click Add Client, then open its workspace and add work areas.

No installation, administrator access, .NET download, account or internet
connection is needed to use the application. Keep all extracted files together.
A first launch starts empty unless an existing CA Desk database is found.

Changes are automatically saved in:
%LOCALAPPDATA%\CADesk\Data\cadesk.db

To update: close CA Desk, extract the newer release into a new folder and
launch its CA-Desk.exe. Your existing database remains in your Windows profile. v1.1.0 automatically
finds and preserves v1.0.x data from the old CA Desk folder. Future versions
use the permanent CADesk/Data path. Do not switch back to an old executable
after upgrading; keep the legacy database as a recovery copy.

Dashboard: click a summary card to view matching work.
Clients: add an optional due date and see remaining calendar days; switch between cards and compact table, or open a client workspace.
Master Work Table: combine search and filters; edit status and dates directly.
Notes: use the purple button on the right to create, search and edit personal
study notes. Each note has a heading, plain-text body and editable date.
Calendar: choose Month, Week or Day; click a work deadline or purple study
note to edit it. Use the event filter to show everything, deadlines or notes.
Client filtering keeps enabled personal notes visible.
Settings: Export Backup saves all data to a new .db filename. Restore Backup
validates a file, asks before replacing current data and keeps a recovery copy.
Daily automatic backups and pre-update/pre-restore copies are saved under:
%LOCALAPPDATA%\CADesk\Backups\
Keep an exported copy on another drive as protection from computer failure.
Removing the portable application does not remove your database or backups.

Keyboard: Ctrl+F focuses page search; Ctrl+N adds a note when Notes is active,
otherwise a client; Ctrl+R refreshes.
Ctrl+S saves an open form; Escape cancels. Unsaved note changes require
confirmation before discarding. The top-right title-bar buttons
minimize, maximize/restore and close CA Desk. Double-click its title bar to
maximize/restore, or drag the title bar to move the window.

Exactly three statuses: Not Started, In Progress and Completed.
Red deadline dates indicate overdue unfinished work. Completing the work removes
it from the overdue count. Removing a deadline is supported.

Distribution is portable and unsigned. No installer is included.
Test evidence and remaining platform limits: see the GitHub release notes.
Private repository: sign in to your GitHub account to download releases.
https://github.com/Fahad-uz/CA-Desk/releases
