# CA Desk v1.1.1 – Personal Profile & Standalone EXE

Open Settings, enter your name under **Your profile** and click **Save name**. CA Desk shows “Welcome back, Name” at the top when it opens, with your name in the left sidebar. You can edit or clear the name at any time. It is saved locally and included in complete backups.

The Windows app is now a **single executable**. Download `CA-Desk-v1.1.1-win-x64.exe`, put it on your Desktop or in another folder and double-click it. Copying only the EXE is supported. The optional ZIP contains the same executable, instructions and notices. No runtime installation or administrator access is required. Embedded libraries are extracted automatically into a temporary cache on first launch.

## Update and keep your data

Close the old app and run the new executable. Clients, work areas, due dates, days remaining, study notes, saved views and backups continue using `%LOCALAPPDATA%\CADesk\Data\cadesk.db`. No schema change is required for the profile name. Legacy v1.0.x data is detected and preserved automatically. Moving or replacing the executable leaves the database in your Windows profile.

## Validation and limits

Publication is gated by core tests, native WPF checks, full-field upgrade and restore checks for 150 fictional clients and 3,000 work areas created by the published v1.0.1 library, and launch of the actual single-file executable. Profile checks cover the real Settings controls, Unicode, whitespace, long-name layout, clearing, restart and backup restoration. The package check launches an EXE-only copy in a separate Desktop-style folder with spaces, from an unrelated working directory, using a fresh extraction cache; it exercises WPF, native SQLite, the profile greeting, backup and all title-bar buttons.

Windows 10/11 x64 target. Native verification runs on GitHub-hosted Windows Server; physical Windows 10/11 machines and all display scaling settings have not been tested. Distribution is portable and unsigned. Existing releases are preserved.
