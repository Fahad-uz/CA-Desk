CA Desk v1.0.1 adds clearly visible window controls in the application's title bar.

- **Minimize** sends the window to the taskbar.
- **Maximize** expands the window and changes to **Restore**, which returns to its previous size.
- **Close** exits the application window.
- Each button has a tooltip, accessible name, keyboard focus and hover feedback. The Close button highlights red on hover.
- Native window movement, edge resizing, double-click maximize/restore and the Windows system menu remain available.

Download **CA-Desk-v1.0.1-win-x64.zip**, extract **all** files into a new folder and double-click **CA-Desk.exe**. The .NET runtime is included. Close the old version before launching this one.

Your existing clients, work areas, deadlines and notes remain in `%LOCALAPPDATA%\CA Desk\ca-desk.db`; this update does not change the database schema.

The Windows release workflow runs core and native WPF checks and independently launches the self-contained executable to exercise Minimize, Maximize, Restore and Close, plus SQLite persistence, before publication. The release includes a SHA-256 checksum.

Known limitations: portable and unsigned; no installer. Automated native execution uses a GitHub-hosted Windows Server runner. Physical Windows 10/11 and every display-scaling setting have not been verified. The application's .NET 10 Windows support policy remains unchanged. Sign in to GitHub with access to the private repository to download the release; the app itself runs offline without an account.
