# CA Desk v1.1.0 – Study Notes

Personal study notes now have a dedicated Notes page, with a purple notebook button on the right. Create, edit, search and delete notes with a heading, multiline plain-text body and editable date. Multiple notes can share a date. Ctrl+N creates a note while Notes is active; Ctrl+S saves. The editor warns before discarding unsaved changes.

Every study note appears in purple on its date in month, week and day calendars. Click it to open its full contents. Heading/date edits and deletion update the calendar immediately. Choose Show Everything, Client Deadlines Only or Study Notes Only. Client filtering continues to apply to work deadlines while personal notes remain visible. Notes do not affect client progress or dashboard work totals.

Clients now support optional due dates, with days remaining, due-today and overdue indicators on cards, in the compact table and in client workspaces. Day counts use calendar days.

## Update without losing data

Close CA Desk, download `CA-Desk-v1.1.0-win-x64.zip`, extract all files into a new folder and launch `CA-Desk.exe`. The package includes the runtime; developer tools, administrator access and internet access are unnecessary for normal use.

This version automatically detects v1.0.x data in `%LOCALAPPDATA%\CA Desk\ca-desk.db`, validates it and transfers it to the permanent `%LOCALAPPDATA%\CADesk\Data\cadesk.db` location. The original and a verified backup are kept. Ordered transactional migrations preserve clients, work areas, IDs, relationships, statuses, deadlines and work notes while adding client due dates, personal notes and saved preferences. Future releases use the same permanent location.

Settings provides Export Backup and Restore Backup. Complete backups include personal notes, client due dates and saved calendar/client-view preferences. A selected restore is validated before confirmation; current data is backed up first and the result checked before refresh. Automatic daily backups keep the newest 14 copies under `%LOCALAPPDATA%\CADesk\Backups`. Pre-update, legacy and pre-restore recovery copies are retained separately. A failed schema update rolls back and offers recovery; it never initializes a replacement empty database. Keep exported copies on another drive.

The portable app has no uninstaller. Deleting its extracted application folder leaves profile data intact. Keep using the new executable after upgrading; the old profile copy is retained for recovery. Arbitrary downgrades are unsupported, and incompatible newer databases are refused.

## Validation and limits

The pre-release Windows validation passed 46 core tests, 83 native WPF checks, 10 upgrade checks against a database created by the published v1.0.1 library, and launch of the actual self-contained executable. The release workflow repeats these gates before publishing. Upgrade checks compare every stored field for 150 fictional clients and 3,000 work areas, verify progress/calendar/master entries and restore backups. Failed migration rollback and recovery are covered by automated core tests. No real client data is used or distributed.

Target: Windows 10/11 x64, within .NET 10's supported Windows editions. Native verification runs on GitHub-hosted Windows Server; physical Windows 10/11 machines and every display-scaling setting have not been tested. Distribution is portable and unsigned; no installer, rich text, attachments, cloud synchronization, reminders or AI features are included.
