CA Desk is an offline Windows desktop workspace for Chartered Accountants.

- Live dashboard counts, status distribution chart, client progress and nearest unfinished deadlines.
- Client cards and compact table; create, rename, edit and confirmed deletion.
- Unlimited custom work areas with exactly three statuses, editable/removable deadlines and multiline notes.
- Central Master Work Table with combined search, status/deadline/client filters and sortable columns.
- Month, week and day calendars, today navigation, client filtering and overflow drill-down.
- Transactional local SQLite persistence with foreign keys, schema versioning and a writable user-profile data folder.
- Native Windows window controls, resizing, keyboard shortcuts and inline editing.

Download **CA-Desk-v1.0.0-win-x64.zip**, extract all files, and open **CA-Desk.exe**. The .NET runtime is included; no developer tools, account, administrator permission or internet connection is needed to use the app. GitHub sign-in is needed to download this private release.

Data is stored in `%LOCALAPPDATA%\CA Desk\ca-desk.db`. To update, close CA Desk and extract the next release into a new folder. Your saved data remains in the Windows profile.

The release pipeline builds and tests on a GitHub-hosted Windows runner, exercises and renders the actual WPF interface, and launches the published self-contained executable against an isolated SQLite database before packaging. Test results and screenshots are available in the corresponding Actions run.

Known limitations: portable and unsigned; no installer. Physical Windows 10/11 laptop acceptance and display-scaling checks require those devices; the automated runner uses Windows Server. No notifications, cloud services or accounting calculations are included. This app targets Windows 10/11 x64; Microsoft's current .NET support policy for Windows 10 applies (LTSC/Enterprise versions listed in https://learn.microsoft.com/dotnet/core/install/windows). Consumer Windows 10 editions and older Windows builds have not been verified on physical devices.
