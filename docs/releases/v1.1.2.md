# CA Desk v1.1.2 – Visible Startup Controls

Fixed the window opening beyond the usable screen area on smaller or scaled displays. Close, Minimize and Maximize/Restore now remain inside the screen when the app first opens. The window sizes itself to the current monitor, adapts its minimum dimensions and keeps the custom caption inside visible maximized bounds. Display and work-area changes recheck placement.

Download `CA-Desk-v1.1.2-win-x64.exe`, close the old app and run the new executable. You can keep just the EXE on your Desktop. Existing clients, work areas, due dates, study notes, profile name and preferences keep using the same database; this update changes no data schema.

Publication is gated by core and window-placement tests, native WPF checks, previous-release upgrade checks and launch of an EXE-only copy. New checks verify actual caption screen coordinates and input on first launch before any minimize/restore, maximized and restored bounds, and opening directly maximized. Geometry tests cover 100%, 125%, 150% and 200% display scales, taskbar offsets and secondary monitors with negative coordinates.

Windows 10/11 x64 target. Native execution uses a GitHub-hosted Windows Server runner; every physical display and scaling arrangement has not been tested. Portable and unsigned.
